# OctoWoW-Fishing-helper

Личный комплект для OctoWoW / Vanilla WoW 1.12.1 на Windows x64. Поплавок ищется по изменению системного курсора, клёв — по нашему трёхтональному звуку. Бот обновляет наживку, открывает контейнеры и останавливается через заданное число минут.

[Скачать ZIP с GitHub](https://github.com/kolodidon/OctoWoW-Fishing-helper/archive/refs/heads/main.zip). После скачивания распакуйте архив полностью.

## 1. Установка

1. Скачайте и **полностью распакуйте** этот комплект. Не запускайте установщик из окна ZIP.
2. Закройте WoW. Подключение к интернету потребуется для зависимостей SuperAPI и зависимостей, а при необходимости — Python/SuperWoW.
3. Дважды нажмите **`Install.cmd`**.
4. Укажите папку клиента, в которой лежат `WoW.exe` и `Data`, например `C:\MyPrograms\OctoWow`.
5. Укажите, сколько минут **фактически** действует наживка на вашей удочке: **10**.
6. Дождитесь сообщения «Установка завершена».

Python заранее ставить не обязательно. Если подходящего Python 3.11 x64 нет, установщик скачает Python 3.11.9 с python.org, проверит SHA-256 и установит для текущего пользователя в `%LOCALAPPDATA%\FishingBot\Python311`. PATH и системные политики выполнения не изменяются. Существующий Python 3.11 x64 используется, если он обнаружен.

Установка требует доступа на запись в выбранную папку. Для клиента в защищённой папке может понадобиться запуск с правами администратора. Установщик сам повышение прав не запрашивает.

## 2. Что появится в папке игры

```text
<клиент>/
  Start Fishing Bot.lnk       ← запуск бота
  Start WoW for Fishing.lnk   ← запуск игры через выбранный загрузчик
  FishingBot/
    start.cmd
    .venv/                   ← отдельное окружение Python
    cursor_test.py
    audio_detector.py
    FishBite-reference.wav
    lure-settings.json
    installation.json
    QUICKSTART.txt
    macros/
    backups/                 ← копии изменённых файлов и журнал установки
  Interface/AddOns/
    SimpleAutoDelete/
    SuperAPI/
    FishingBotSetup/
  Sound/Spells/Tradeskills/FishBite.wav
```

Установщик автоматически:

- проверяет контрольные суммы комплекта и целостность вложенного ZIP;
- создаёт окружение и устанавливает закреплённые зависимости;
- устанавливает **нашу адаптацию** SimpleAutoDelete из комплекта;
- скачивает SuperAPI напрямую у автора на закреплённом коммите и проверяет SHA-256;
- устанавливает игровой звук, совпадающий с эталоном бота;
- при наличии VanillaFixes сохраняет все записи `dlls.txt` и добавляет SuperWoW, если записи нет;
- если загрузчика нет и клиент не содержит списка других DLL, устанавливает официальный SuperWoW launcher;
- скачивает отсутствующие файлы **SuperWoW 2.2** у автора и сверяет SHA-256 архива; DLL не входит в распространяемый комплект;
- сохраняет существующий SuperWoW; его реальная версия проверяется уже в игре аддоном;
- создаёт ярлыки и устанавливает интервал наживки 300 или 600 секунд в команде запуска.

Игра и бот автоматически не запускаются. `WoW.exe`, realmlist, пароли, `WTF`, персональные фильтры удаления, панели и привязки клавиш не редактируются. OctoLogin и AutoLogin не нужны для рыбалки и этим установщиком не устанавливаются.

Если в клиенте есть другие DLL, но нет VanillaFixes, установщик остановится с пояснением. Он не пытается угадать нестандартный загрузчик и отключить существующие моды. Запускайте его повторно после подготовки совместимого загрузчика.

## 3. Один раз подготовьте игру

1. Запустите **`Start WoW for Fishing.lnk`**. Если загрузчик спрашивает о DLL, разрешите загрузку.
2. На экране выбора персонажа включите **SuperAPI**, **SimpleAutoDelete** и **FishingBotSetup**.
3. После входа в игру введите:

   ```text
   /fishsetup
   ```

   Команда создаёт два макроса и включает автолут через SuperAPI. Существующий одноимённый макрос с другим содержимым она не перезаписывает. Если места для макросов нет, освободите два слота и повторите команду.

4. Разложите действия на панели, привязанной к обычным верхним клавишам:

   | Клавиша | Действие                                                          |
   | ------- | ----------------------------------------------------------------- |
   | **1**   | Fishing из книги заклинаний                                       |
   | **2**   | Макрос **FB-Lure** — Aquadynamic Fish Attractor на надетую удочку |
   | **3**   | Макрос **FB-Boxes** — открыть один контейнер                      |

5. Проверьте все три клавиши вручную. Макросы используют английские названия предметов; на другой локализации их нужно заменить.
6. Проверьте автолут: улов и содержимое контейнера должны собираться **без Shift**. При инверсии из-за Vanilla Tweaks quickloot выполните `/fishsetup autoloot off` и проверьте снова. `/fishsetup autoloot on` возвращает обычный режим.
7. Звук игры направьте на устройство вывода Windows по умолчанию. Музыку и фон выключите, эффекты оставьте включёнными. При клёве должен звучать наш трёхтональный сигнал.

Удочка должна быть надета, наживка — находиться в сумках. Бот не производит наживку и не проверяет, удалось ли макросу её применить.

## 4. Первый запуск

1. Поставьте персонажа к воде, закройте лишние игровые окна.
2. Откройте **`Start Fishing Bot.lnk`** в папке клиента.
3. Введите **2 минуты** для испытания.
4. Во время 10-секундного отсчёта переключитесь в WoW и оставьте курсор неподвижно над пустой водой.
5. Проверьте применение наживки, поиск поплавка, подсечку и открытие контейнера.

**F8 или Esc** прекращают работу, оставляя игру открытой. **По истечении введённого времени бот закрывает исходное окно WoW.** После десяти неудачных поисков подряд бот останавливается без закрытия игры.

Для работы игра должна быть активной. Бот использует общую мышь и клавиатуру. После изменения положения/размера окна перезапустите бот. Другие приложения со звуком тоже попадают в аудиозахват.

## 5. Очистка сумок — только после выбора предметов

На новом персонаже автоочистка **выключена**, список **пуст**. Ничего не будет автоматически удаляться до настройки.

```text
/sad off
/sad add <ссылка на ненужный предмет>
/sad list
/sad test
/sad on
```

Чтобы добавить ссылку, напишите `/sad add ` с пробелом, затем Shift-кликните предмет в сумке. `/sad test` показывает, что будет удалено, ничего не уничтожая. Включайте `/sad on` только после проверки. Удаляется **вся стопка** указанного предмета.

`/sad off` выключает автоочистку. `/sad status` показывает состояние. `/sad run` запрашивает настоящее удаление даже при выключенной автоочистке.

Файл `FishingBot\macros\sad-fish-list.txt` содержит прежний личный список для справки. Установщик его не активирует.

## 6. Настройки и обновление

Размещение комплекта после установки можно менять или удалить: установленный бот работает из папки клиента. Окружение `.venv` зависит от Python, которым оно создано; сам Python не удаляйте.

Для изменения интервала наживки повторите установку и выберите 5 или 10 минут. Либо измените число после `--lure-interval` в `FishingBot\start.cmd`: это секунды, например `300`. `lure-settings.json` — запись выбранной при установке настройки; запуск использует значение из `start.cmd`.

Остальные параметры можно проверить коротким запуском из `FishingBot`:

```powershell
.\start.cmd --step 60 --settle-ms 40 --timeout 5
```

Подробная калибровка поиска и аудио — в [подробном руководстве](README-detailed.md). Алгоритм поиска/подсечки прежний; для установщика добавлен только параметр `--lure-interval`.

Повторная установка обновляет файлы комплекта, сохраняет резервные копии заменяемых файлов и не сбрасывает игровые SavedVariables. Собственные изменения Python-кода также будут скопированы в резервную копию, если установщик заменит их.

При ошибке на этапе записи установщик пытается вернуть изменённые им файлы. Уже созданное окружение Python может остаться для повторной установки. Журнал изменений находится в `FishingBot\backups\<дата>\manifest.json`; старые файлы — в подпапке `files` с исходными относительными путями. Файлы, изменённые параллельно другим процессом, не перезаписываются при откате. Для ручного восстановления закройте игру и используйте этот журнал; не переносите всю папку резервной копии поверх игры без сверки путей.

## 7. Если что-то не работает

| Симптом                                    | Действие                                                                                                   |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| Установщик просит закрыть WoW              | Полностью выйдите из игры и повторите Install.cmd                                                          |
| Ошибка контрольной суммы                   | Заново скачайте/распакуйте комплект; не отключайте проверку                                                |
| Ошибка загрузки SuperWoW                   | Проверьте интернет/доступ к GitHub и повторите установку                                                   |
| Python не устанавливается                  | Установите Python 3.11 x64 самостоятельно и повторите установку                                            |
| Install.cmd завершается до вопроса о папке | Запустите `py -3.11 install.py` из комплекта, если Python уже установлен                                   |
| Пишет, что FishingBot уже существует       | Это не папка данного установщика. Не удаляйте её вслепую; переименуйте или перенесите самостоятельно       |
| `/fishsetup` не работает                   | Проверьте включение FishingBotSetup и запуск клиента через правильный ярлык                                |
| SuperAPI сообщает об отсутствии SuperWoW   | Существующая DLL могла быть старой или не загрузиться. Обновите мод по официальной инструкции, сохранив старый |
| Не создаются макросы                       | Свободные слоты, SuperWoW >= 2.2, SuperAPI и лимит 511 символов                                            |
| Кнопка 2 ничего не делает                  | Надетая удочка, Aquadynamic Fish Attractor в сумках, макрос на клавише 2                                   |
| Бот не находит поплавок                    | Стартовый курсор над пустой водой, FPS, размер окна; затем калибровка из README                            |
| Поплавок найден, но подсечки нет           | Реальный трёхтональный звук, громкость и устройство вывода Windows                                         |

Журналы бота: `FishingBot\last-result.json`, `cycles.jsonl`, `audio-matches.jsonl`. Аудиожурнал содержит оценки, не запись звука; его можно удалить при остановленном боте, если он вырос слишком большим.

## 8. Скачивание и хранение

В репозиторий загружается **полный распакованный комплект установщика**, включая `installer`, вложенный ZIP и SHA256SUMS.txt. При скачивании снова распакуйте все файлы и запускайте Install.cmd.

Не загружайте установленную папку клиента, `.venv`, журналы, резервные копии или `WTF`. DLL SuperWoW скачивается установщиком у автора и в комплект не включена. SuperAPI также скачивается напрямую у автора. В комплекте остаётся адаптация SimpleAutoDelete с оригинальной MIT-лицензией. Источники и условия сторонних компонентов описаны в [THIRD-PARTY.md](THIRD-PARTY.md).

Источники: [SuperWoW](https://github.com/balakethelock/SuperWoW), [SuperAPI](https://github.com/balakethelock/SuperAPI), [SimpleAutoDelete](https://github.com/fondlez/SimpleAutoDelete), [Python](https://www.python.org/downloads/windows/).

Автоматизация установки не подтверждает совместимость каждого клиента: реальный ввод, аудио, загрузка DLL и макросы проверяются коротким игровым запуском пользователем.
